    A[Phase 1: Architecture & Planning] --> B[Phase 2: UI/UX & Motion Engineering]
    B --> C[Phase 3: Android IME & Core Implementation]
    C --> D[Phase 4: Performance, Testing & Security]
    D --> E[Phase 5: CI/CD, Documentation & Release]

    subgraph "Phase 1: Architecture"
        A1[superpowers / writing-plans]
        A2[senior-architect / c4-architecture]
        A3[conductor-implement]
    end

    subgraph "Phase 2: UI/UX & Motion"
        B1[ui-ux-pro-max / mobile-app-ui-design]
        B2[emil-kowalski-design-engineering / apple-design]
        B3[impeccable / design-system]
    end

    subgraph "Phase 3: Android Engine"
        C1[edge-to-edge / common-mobile-ux-core]
        C2[adaptive-layouts / component-scaffold]
        C3[multi-platform-apps / android-cli]
    end

    subgraph "Phase 4: Quality & Hardening"
        D1[jetpack-compose-performance]
        D2[security-auditor / security-scanning-hardening]
        D3[code-review-ai-ai-review / unit-testing]
    end

    subgraph "Phase 5: Release & Publish"
        E1[github-actions-templates / cicd-automation]

    end

## 3. Quick Reference for Triggering Skills

- **To plan a new feature**: Activate `superpowers` + `senior-architect`.
- **To style keyboard UI & floating bar**: Activate `ui-ux-pro-max` + `mobile-app-ui-design`.
- **To add Keys Cafe style key-press animations**: Activate `emil-kowalski-design-engineering`.
- **To fix keyboard overlapping system bars / navigation**: Activate `edge-to-edge`.
- **To eliminate Compose recomposition lag / stutter**: Activate `application-performance-optimization` + `jetpack-compose-performance`.
- **To secure Groq API keys & protect against banking apps**: Activate `security-scanning-hardening` + `security-auditor`.
- **To configure automated release builds**: Activate `github-actions-templates` + `deployment-validation-config-validate`.
- **To generate launch materials and disclosures**: Activate `documentation-generation-doc-generate` + `copywriting` + `brag`.
